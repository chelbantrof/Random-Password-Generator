# Random-Password-Generator

**Автор:** Чебан Трофим

## Описание

Приложение с графическим интерфейсом для генерации случайных паролей.  
Позволяет настраивать длину пароля, использовать цифры, буквы и спецсимволы.  
Все сгенерированные пароли сохраняются в историю (файл `password_history.json`).  
Есть возможность копирования пароля в буфер обмена, очистки истории.

## Требования

- Python 3.6+
- Стандартные библиотеки: `tkinter`, `random`, `string`, `json`, `os`, `datetime`

## Запуск

```bash
python password_generator.py
